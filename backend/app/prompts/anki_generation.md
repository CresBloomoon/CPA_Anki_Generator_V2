【重要】テキストに含まれる**すべての論点（見出し、小見出し、太字箇所、表形式の定義など）**を漏れなく1論点として内容を抽出し、
論文式試験用のAnkiカードデータをJSON形式で出力してください。
「短答：A」「論文：C」などのランクが付されている箇所はもちろん、**ランクの記載がない重要キーワードや定義も、試験上必須の知識として必ずカード化してください。**
原則は1論点につき1カード（1項目）ですが、1論点あたりの分量が多くなる場合（記憶負担が大きくなる場合）は、
必ず1論点に対して2枚以上のカードに分割して生成してください。**「漏れ」は絶対に許されません。**

【必須出力フォーマット】
JSON形式で出力してください。ルートは "cards" というキーを持つオブジェクトとし、その値は配列としてください。
配列内の各カード要素は以下のキーを必ず持たせてください。欠落のないようにしてください。
- "TITLE": 論点のタイトル（例：「発起人の権限」「設立無効の訴え」等）。短く簡潔に。
- "QUESTION": 表面の問い。「[TITLE]について述べよ」等の形式。（例：「発起人の権限について述べよ」）
              ※絶対に「〜について述べよ」というテンプレート文字列をそのまま出力しないでください。実際の言葉を入れてください。
- "RONSHO_BODY": 論証の本文。テキストから読み取れる**実際の論証や趣旨・要件・効果**を詳細に記述してください。「趣旨」「要件」といった単語だけを出力してはいけません。
- "KAISETSU_BODY": 本論点についての詳細な解説。PDFの内容に基づいた具体的な解説を長文で必ず記述してください。
- "YO_SURUNI_BODY": 「要するに？」に対する回答。本論点の核心を、たとえ話や具体的なイメージを交えて徹底的に噛み砕いて説明してください。まずここを見て理解の糸口とするため、充実した記述（3〜5文程度以上）を心がけてください。
- "RYUI_BODY": 留意点や注意点。該当しない場合でもなるべくテキストから探して記述するか、「特になし」などとしてください。
- "RANK_TANTO": 短答式試験でのランク（例：「A」「B」「C」）。テキストになければ推測せず「-」でよいですが、なるべく抽出してください。
- "RANK_RONBUN": 論文式試験でのランク（例：「A」「B」「C」）。テキストから抽出してください。
- "PAGE_CODE": PDFの下部中央付近に記載された独自のページコード（例：③-8-1）。プロンプトの例示ではなく、必ずPDFの【テキスト】から実際の値を抜き出してください。
- "TAGS": プロジェクト指示文に従い、その論点に対応するタグを文字列のリストとして出力してください。（例： ["chap35", "ronbun:B", "tanto:C", "section4"] など）

【指示】
1. 各論点について、必ず【テキスト】の内容を要約して値に入れてください。中身が空っぽにならないように最大限注意してください。
2. 特に "KAISETSU_BODY" や "RONSHO_BODY" には、PDFのテキストの文言を活かし、詳細な解説を記述してください。
3. 1つの論点の分量が多すぎる場合は、自動的に複数枚のカードに分割してください。
4. 【重要】教科書・テキスト上で太字になっている箇所や、試験上重要なキーワードは、必ずHTMLタグの `<b>太字テキスト</b>` を用いて強調表示を反映させてください。

【テキスト】
${text_chunk}

【重要】
返答は思考プロセスを除き、必ず { で始まり } で終わるJSON形式のみを出力してください。余計な解説は一切不要です。
